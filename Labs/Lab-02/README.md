# Лабораторная работа №2. Исследование частотных свойств файлов, как источников символов

### Задание 1.

- Сформировать файл из латинских символов случайным образом. Кодировка файла - ASCII, размер - 100000 символов.
- Найти и рассчитать следующие информационные параметры сгенерированного файла:
  - объем
  - энтропию
  - количество информации (энтропия, умноженная на кол-во символов)
  - избыточность
- зашифровать файл шифром Цезаря и повторно рассчитать показатели из предыдущего пункта
- сжать файл архиватором ZIP или RAR и оценить степень сжатия 

### Задание 2. 

- Взять из папки **Data** текущего репозитория файл с текстом романа "Война и мир" на английском языке и имеющего кодировку ASCII
- оценить информационные параметры из Задания 1 для файла с романом
- сжать файл тем же самым архиватором, что и при выполнении Задания 1
- сравнить результаты с результатами Задания 1 и сделать выводы

### Задание 3.

- Взять из папки **Data** текущего репозитория файл с текстом романа "Война и мир" на русском языке в кодировке UTF-8
- найти частоты встречаемости русских букв
- вычислить информационные параметры из Задания 1
- сжать файл тем же самым архиватором, что и при выполнении Задания 1
- сравнить результаты с результатами задания 2 и сделать выводы

### Задание 4.

- сделать глобальные выводы по работе
