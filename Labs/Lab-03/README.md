# Лабораторная работа №3. Изучение алгоритма сжатия при передачи данных ''стопка книг''

### Задание 1.

- взять из папки **Data** текст программы **mtf.py** и адаптировать его под использование с файлом **war_peace.txt**, находящимся в той же папке.

- сформировать префиксный код (любой) для ASCII-таблицы, расположив символы по убыванию частоты встречаемости символов
- закодировать содержимое **war_peace.txt** префиксным кодом и подсчитать, сколько нулей и единиц будет в этом закодированном файле
- сжать файл архиватором ZIP или RAR исходный файл и закодированный файл. Оценить степень сжатия двух файлов и сравнить

### Задание 2. 

- Подсчитать, сколько нулей и единиц будет передано по виртуальному каналу связи, если передавать нули и единицы с использованием алгоритма **MTF** (''стопка книг'')

### Задание 3.

- сравнить размер в '0' и '1' закодированного в задании 2 файла с результатом подсчета в задании 3 и сделать выводы
