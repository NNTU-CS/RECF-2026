# Лабораторная работа №5. Генерация и визуализация сигналов

### Задание 1.

- запустить **Microcap** и с помощью встроенных генераторов сигналов сформировать а) экспоненциальный сигнал с шумом б) радиоимпульс
- полученные сигналы сохранить в файлах с отсчетами **1.usr** и **2.usr**

### Задание 2. 

- визуализировать сигналы с помощью программы **vis.py** из папки **Data**

### Задание 3.

- сформировать из гармоник треугольный периодический сигнал, используя программы **garm-1**, **garm-2** и **garm-3** из папки **Data**
- сформировать файл с анимацией 
- изучить процесс создания анимации в **Jupyter Notebook** для расчета и демонстрации формирования сигнала из гармоник
