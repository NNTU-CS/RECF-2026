# Лабораторная работа №4. Моделирование каналов дискретных сообщений с использованием корректирующих кодов

### Задание 1.

- взять из папки **Data** текстовый файл **war_peace.txt** и закодировать его содержимое ПОБАЙТНО в виде строки из '0' и '1'
- построить модель канала для передачи двоичных сообщений и с установленной вероятностью ошибки при передаче одного бита сообщения
- добавляем к каждому байту бит четности (сумма по модулю 2 всех единиц) и передаем в канал (в виде строки)
- на приемной стороне анализируем бит четности и в случае несовпадения суммы единиц и бита четности, запрашиваем передачу байта повторно
- суммируем все переданные '0' и '1' для всего файла (включая и бит четности)


### Задание 2. 

- закодировать соедржимое **war_peace.txt** с помошью кода Хэмминга (разделив каждый байт на блоки по 4 бита) 
- организовать передачу через канал с ошибками с обнаружением ошибки на приемной стороне и восстановлением искаженного бита
- суммируем все переданные '0' и '1' для всего файла (включая и контрольные разряды)

### Задание 3.

- провести эксперимент и построить зависимость количества переданных байт в задании 1 и количества переданных байт в задании 2 от вероятности ошибки в канале
- сравнить между собой два подхода: с использованием бита четности и с использованием кода Хэмминга
